Проекты

Избранные работы — боты, сайты и мини-приложения

  • 01
    saas · avito

    Droprelay

    Операционка для дропшиппинга на Avito: поставщики, каталог товаров, XML-фид для объявлений, заказы и алерты в Telegram, когда что-то ломается или нужна реакция.

    Для продавца, который ведёт много карточек и не хочет собирать всё руками в таблицах — один контур от поставщика до витрины.

    Next.js 15 · TypeScript · Zod · JSON store

  • 02
    сайт · коммерция

    МЕТПРОФ

    Сайт строительной компании: аренда спецтехники, каталог, заявка с сайта. Для менеджера — PWA-админка с календарём занятости техники.

    Откройте сайт → выберите технику → оставьте заявку. Админка ставится на телефон как приложение.

    Flask · PWA · Vanilla JS

  • 03
    mini app · ai

    Room Remix

    Помогает представить ремонт до покупки: загружаете фото комнаты, выбираете стиль и бюджет — бот отдаёт рендер, план и подбор товаров. Оплата в Telegram Stars.

    Откройте @reroom_app_bot → Start → загрузите фото → выберите стиль. Дальше всё внутри Mini App.

    aiogram 3 · aiohttp · fal.ai · Stars

  • 04
    бот · web app

    HabitGo

    Трекер привычек и общих задач для себя или небольшой команды: серии (streak), календарь, роли, назначение дел по @username.

    Откройте @HabitGoBot → создайте привычку или группу → отмечайте дни. Удобно смотреть прогресс в Mini App.

    aiogram 3 · SQLite · Mini App

  • 05
    бот · web app

    Raschetka

    «Кто кому должен» без хаоса в чате: книга долгов, делёжка чека по позициям или поровну, напоминания участникам. Чек можно сфоткать — бот разберёт позиции.

    Откройте @raschetka_tab_bot → Start → добавьте долг текстом или откройте Mini App для делёжки чека. В профиле можно указать реквизиты для перевода.

    aiogram 3 · Groq · Web App

  • 06
    бот · платежи

    Голос Путника

    Таро с авторской колодой в Telegram: первая карта бесплатно, дальше — подписка через ЮKassa. Для тех, кто хочет короткий ритуал и трактовку без приложений со стороны.

    Откройте @Tarot_opora_bot → Start → вытяните карту. Оплата и подписка — прямо в боте.

    aiogram 3 · ЮKassa · aiohttp

  • 07
    бот · ai

    AI Style Bot

    Перерисовка фото в стили (аниме, GTA, акварель, реставрация и др.) с сохранением лиц. Можно оживить кадр в короткое видео. Баланс пополняется Stars или СБП.

    Откройте @ai_art_pro_bot → выберите стиль → пришлите фото → дождитесь результата. Если баланс пуст — пополните кошелёк в меню бота.

    aiogram 3 · fal.ai · FLUX

  • 08
    приложение · edtech

    Искра

    Ежедневная привычка узнавать мир: тема дня, короткие курсы, карточки, тесты, XP и streak. Можно спросить нейросеть, если что-то непонятно.

    Откройте приложение в браузере → зайдите в тему дня или курс → пройдите карточки и тест. Прогресс хранится у вас на устройстве.

    Next.js · localStorage · OpenAI

  • 09
    игра · яндекс

    Тихий дом

    Детективная игра про Зареченск 1994: собираете улики, допрашиваете, закрываете дела («Тихий дом на окраине», «Касса на Советской»). Цель — Яндекс.Игры.

    Откройте демо → выберите дело → исследуйте локации и улики. Управление мышкой/тачем, без установки.

    Vite · TypeScript · Yandex Games SDK

  • 10
    бот · ai

    Danetka AI

    Классическая «данетка»: бот загадывает историю, вы задаёте вопросы, на которые можно ответить только «да», «нет» или «неважно». Есть подсказки, каталог загадок и рейтинг.

    Откройте @danetka_game_bot → Start → начните игру и пишите вопросы обычным текстом. В группе тоже можно играть вместе.

    aiogram 3 · OpenAI · SQLAlchemy

  • 11
    бот · игра

    Дополни фразу

    Игра для компаний в Telegram: бот кидает начало фразы, все дописывают ответ реплаем, потом голосуют в опросе. Очки копятся по раундам.

    Добавьте @PunchRoundBot в группу → /play → отвечайте реплаем на сообщение с фразой → голосуйте. /score — очки, /stop — итог.

    aiogram 3 · опросы Telegram · FSM
